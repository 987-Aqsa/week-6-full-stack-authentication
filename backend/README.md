# Week 4 - MongoDB Powered REST API

A REST API built using Node.js, Express.js, MongoDB Atlas, and Mongoose.

## Features

- MongoDB Atlas database integration
- Mongoose schema and model
- Create tasks
- Get all tasks
- Get a single task
- Update tasks
- Delete tasks
- REST API testing with Postman
- Environment variables for database credentials

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman
